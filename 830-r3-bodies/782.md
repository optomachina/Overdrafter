## Summary

Adds a sanity gate (`worker/src/fixtureHeal/`) on every live quote before it is persisted, displayed or routed, on both the generic provider pipeline (step 6→7, `deps.sanity`, after `validateProviderResult`) and the Xometry `handleVendorQuoteTask` path (before `finalizeVendorQuoteResult` and `computeAndStoreRoutingScores`). The first outlier holds the quote as `manual_review_pending` (offers withheld into `raw_payload.fixtureSanity`) and pauses the supplier (per-process until OVD-771; no timer release).

## Problem

Supplier page drift can produce `-`/zero prices, wrong echoed material/qty/thickness, or outlier prices that would reach customers. Xometry bypassed `validateProviderResult` entirely.

## Acceptance criteria addressed

- [x] Rules: missing/`-`/zero price, echo mismatch (material/thickness/qty), unit×qty arithmetic, history/peer outlier
- [x] Hooked into the pipeline and the Xometry path; gate runs before routing scores; held quotes skip routing scores
- [x] First outlier holds + pauses + pages/logs; no midnight auto-release
- [x] Paused supplier admits only internal test quotes (`raw_payload.fixtureHeal.internal=true`, internal org, golden part); kill switch still blocks them
- [x] No migration

## Files changed

- `worker/src/fixtureHeal/{sanity,sanityHistory,pause,gate}.ts` + tests
- `worker/src/providerTaskPipeline.ts`, `worker/src/providerTaskRoute.ts`, `worker/src/index.ts`

## Scope

Included: worker-side gate, pause, internal-quote marking (internal results are always held with no offer rows, so nothing to publish/select).
Not included: SQL publish/select guards (S4 draft), durable pause (S2/OVD-771), cross-quantity price comparison. The thickness echo rule exists but no adapter emits a thickness echo yet. `FIXTURE_HEAL_INTERNAL_ORG_IDS` / `FIXTURE_HEAL_GOLDEN_PART_IDS` default empty.
