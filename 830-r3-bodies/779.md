## Summary

Adds `server/design-graph/`, the hardware design graph contract and a CAD-only router: `DesignGraph.submit(request) -> runId` runs intake -> concept_picks -> domain_agent -> verify -> result. It includes a `DomainAgent` registry with per-agent enable flags (only `cad` is enabled), typed events with runtime validation, and an import-boundary check.

## Problem

Jarvis needs one choke point that every request has to pass through, so no UI or channel code can reach a worker any other way (OVD-795 design §3).

- [x] `DesignGraph.submit` with nodes intake -> concept_picks -> domain_agent(cad|optics|electronics|analysis) -> verify -> result

- [x] Import-boundary check (G-5)
