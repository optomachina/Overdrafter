## Summary

After upload/drawing processing the Xometry adapter reads back auto-selected process, material and finish, overwrites them with the saved requirement, reads back again, and fails with `saved_requirement_mismatch` only if they still differ.

## Problem

T1 live run: (1) "as machined" produced no finish terms, so Xometry's drawing-derived Black Anodize stayed and the run failed on finish; (2) a no-drawing plate defaulted to Sheet Cutting / Aluminum 5052-H32 and 6061 was never applied.

## Acceptance criteria addressed

- [x] 'as machined' actively selects As Machined, clearing the auto Black Anodize (including when the drawing re-derives it after attach).
- [x] No-drawing plate gets CNC Machining + Aluminum 6061, not Sheet Cutting/5052.
- [x] Second read-back; mismatch only if still different. Process added to verification; payload adds `requestedProcessTerms`.
- [x] Fixture tests for both T1 cases end matching; an unsettable value (option absent) still raises the mismatch.
