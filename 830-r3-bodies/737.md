## Summary

- Stops the flaky SQL CI jobs (free-quote-sql, ovd591 capability-sql, ovd591 retention-sql) from failing on public ECR anonymous rate limits by caching the pinned Supabase images and skipping pulls for images already loaded.

## Problem

- Run 38542919223 (Oct 14) failed with 'image-pull: registry public.ecr.aws rate-limited after 5 attempts (budget 300s)'. The OVD-726 retry helper (#668) classifies toomanyrequests correctly, but GitHub runners share egress IPs, so retries alone still exhaust the budget.

## Scope

- scripts/ovd591-image-pull.mjs: opt-in skipLoaded runs docker image inspect first and records status 'cached' instead of pulling a tag-pinned image that is already loaded.
- ovd591-ci-fixture.mjs and free-quote-platform-sources.mjs enable skipLoaded.
- Three workflows: actions/cache@v4 restore + docker load of saved image tarballs; docker save on cache miss after a successful run.
- No secrets, credentials, migrations or RLS touched. Touches .github/workflows, so this needs Blaine's OK to merge.
