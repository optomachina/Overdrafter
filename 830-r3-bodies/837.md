## What is allowed (exactly two package allowances)
The Jarvis import boundary (CS-14) forbids every import that leaves `src/features/jarvis/` or names a worker/queue module. This PR adds `isAllowedPackageImport` with exactly two exceptions:

| Package | Allowed only in | Match rule |
|---|---|---|
| `react` | `src/features/jarvis/thread/` | file path starts with `src/features/jarvis/thread/` (and has no `..` after it) |
| `@google/model-viewer` | `src/features/jarvis/thread/model-loader.ts` | exact path match; no other file, nested or not |

Everything else stays a violation, including server, worker and queue imports.
