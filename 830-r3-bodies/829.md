## Summary
Implements **OVD-890** following the Architect design. Vercel previews are failing with `api-deployments-free-per-day`. That's the Hobby plan's cap of 100 deployments a day; it isn't a broken build. This PR skips deployments that aren't needed.

- `vercel.json`: `"ignoreCommand": "bash scripts/vercel-ignore-build.sh"`
- `scripts/vercel-ignore-build.sh`: exits 0 (**skip**) only when every changed file is under `docs/`, `scripts/`, `.github/`, `supabase/tests/`, or is `*.md` (build inputs such as `scripts/verify-public-assets.mjs`, `scripts/verify-mobile-auth-build.mjs`, `scripts/vite-*` and `public/*` always build). Everything else builds. Production (`VERCEL_ENV=production` or ref `main`) always builds.
  - **Base commit:** if `VERCEL_GIT_PREVIOUS_SHA` is set, it must match `^[0-9a-f]{40}$` and resolve to a commit, fetched with `git fetch --depth=100 -- origin <sha>` only in a shallow clone where it is not already present. Otherwise the script builds: refs like `main`, option-shaped or multi-line values and unknown SHAs never skip, and the value never reaches git unless the whole string is exactly 40 lowercase hex characters.
  - **Unset or empty `VERCEL_GIT_PREVIOUS_SHA`** (a branch's first deployment): the script compares against the merge-base with `origin/main` or `main`. If one exists and the diff is tooling-only, it **skips**. If there is no main ref (typical for Vercel's shallow clone), it builds.
  - **Other errors build** (exit 1): no comparable base, a git diff failure, an empty diff, or no repo.
- Safety change from review: some `scripts/` files are inputs to the deployed build, so they always force a build: `scripts/verify-public-assets.mjs`, `scripts/verify-mobile-auth-build.mjs` and `scripts/vite-*`. Everything under `public/*` also forces a build, including `.md` files, because they ship in `dist`.
- `scripts/vercel-ignore-build.test.mjs`: table-driven tests that run against temporary git repos. Cases: docs-only, md-only and tooling-only skip; src builds; mixed builds; main/production builds; bogus/garbage/ref/uppercase/option-shaped (`--upload-pack=...`) and multi-line SHAs build without executing anything; unfetchable SHA in a shallow clone builds; unset SHA uses the merge-base fallback; build-input scripts build; public md builds.

No new dependencies, no workflow changes, no secrets. The script prints a single reason line.
