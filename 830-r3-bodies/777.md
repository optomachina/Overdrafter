## Summary

Add the missing trailing `\` on the `sonar.cpd.exclusions` line in `.sonarcloud.properties`.

## Problem

The `sonar.cpd.exclusions=` line had no continuation backslash, so the properties parser ended the value there. The next line (`,docs/migration-drafts/ovd-771.sql,...,docs/migration-drafts/ovd-766-*.sql`) was parsed as a separate, meaningless key, and `docs/migration-drafts/ovd-766-*.sql` was never excluded. That is why the Sonar duplication check kept failing on the OVD-766 PRs.
