## Summary

The live-provider harness records per-run artifacts at price capture: flag-gated operator-local screenshots, a redacted DOM snapshot at the price-capture point, and results.jsonl rows linking run id, quote id/URL and artifacts, with 14-day retention.

## Problem

The Q11-6009-0901 root cause (OVD-776) was inconclusive because T1 evidence did not link harness runs to quote ids and had no page state at price capture.

## Acceptance criteria addressed

- [x] Screenshots harness-only, only with `LIVE_HARNESS_SCREENSHOTS=1`, written to an operator-local dir outside the repo (default `~/overnight/artifacts/<runId>/`, 0700). Never uploaded to Supabase, CI, Linear or GitHub.
- [x] Production adapter has no screenshot path of its own; the harness injects a hook typed down to a screenshot method. Tested off unless injected.
- [x] New DOM snapshot at price capture through the existing redactor (alongside existing 'configured' and 'result'); only redacted DOM goes into results.jsonl.
- [x] Each results.jsonl row: runId, provider, requested qty, provider quote id, quote URL (query and fragment stripped), timestamp, artifact paths relative to the artifact root; runId in filenames.
- [x] Retention: run dirs older than 14 days deleted at harness start (only run-id-named dirs, age from the id); standalone cleanup script with `--dry-run` / `--root`.

**Known gaps**
- Quote-id parsing only knows Xometry's URL format. Only Xometry injects the hook and takes the price-capture snapshot; other providers' rows link their existing DOM snapshots with a null quote id.
- No npm script for the cleanup (`package.json` is on the sensitive-paths list). Run with `worker/node_modules/.bin/tsx scripts/cleanup-live-harness-artifacts.ts [--dry-run]`.
- Artifacts are recorded only when the CLI runs or a caller passes `runArtifacts` to `runEvaluationBatch`; library/test callers never write to `~`.
- One existing assertion changed: the live-evaluation adapter test now expects 6 DOM snapshots instead of 5 and confirms no screenshot.
- Diff exceeds the ~200-line guideline, mostly tests and the fixture.
