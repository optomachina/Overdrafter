## Review round 1

Two Codex findings, both fixed in `operatorExportGate.ts`.

1. Fixture bypass trusted location alone. A file under a fixture root now counts as a fixture only when its repo relative path and current SHA-256 appear in `OPERATOR_FIXTURE_MANIFEST`. The manifest starts empty because the corpus is empty, so no file is admitted as a fixture until a reviewed drawing is added with its hash. Untracked, modified, symlinked and missing files are refused.
2. The declaration was not bound to the drawing. Before the declaration check, the gate hashes the local bytes and requires a match against `content_sha256` of a `job_files` row with that `job_id` and `file_kind = drawing`. An unrelated job, mismatched bytes, a lookup error or an unreadable file all refuse, and the declaration RPC is not called.
