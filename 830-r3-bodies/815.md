Fixes [OVD-877](https://linear.app/overdrafter/issue/OVD-877/qa-handoff-job-summary-fence-or-escape-backticks-in-branch-names).

- `scripts/qa-handoff/run.mjs`: `codeFence()` picks a backtick fence longer than any backtick run in the content (min 3); `stepSummary()` builds the job summary with it. `~~~` in values is inert inside a backtick fence. The longest run is found by a single pass over the string, so the scan is safe for any content size (the earlier `Math.max(0, ...runs)` overflowed the stack at about 120k runs).
- `writeStepSummary()` (new): the job summary can never change the job result. If building it throws, a short constant fallback summary is written; if writing throws, the error goes to stderr and nothing is thrown. Every step of that error path is contained: `describeError()` reads the thrown value's message inside try/catch and falls back to the constant `unprintable error` (a throwing message getter, a Symbol, a null-prototype message, a Proxy that throws on every access, `null`), and the `warn()` call is itself wrapped, so a broken stderr writer cannot skip the fallback. `main()` leaves the exit status to the handoff run, so report mode still exits 0 when only the summary fails.
- `main()` is now exported with injectable argv/env/api/summary builder/exit/out/err so the exit-status path is tested in process. The entry guard and CLI behavior are unchanged. `main()`'s own error path uses the same containment: the run-failure line goes through `describeError()` (a thrown `null` or Proxy no longer makes `error.message` throw before the summary is written), stderr goes through a contained writer (a throwing stderr no longer skips `exit(2)` on bad arguments or a missing token), and the log sink records each line before printing it (a throwing stdout cannot lose it from the summary or fail the run).
- `scripts/qa-handoff/step-summary.test.mjs` (new): backtick, triple-backtick, `~~~` and mixed values; whole-line backtick cases; bare CR and CRLF; 200k backtick runs, and a run longer than any default fence, for `codeFence`, `stepSummary` and a 2,500-PR `main()` run (exit 0, full summary); an injected build throw and an unwritable summary path (summary or warning, exit 0); a failed run still exits 1; hostile thrown values (a throwing `.message` getter, a Symbol, a Proxy that throws on every access, a null-prototype message, `null`, `undefined`) from the summary builder, the writer and the run, and throwing stderr and stdout writers, in report and apply mode, each checked for the exit status and the summary that reaches the file.
