## Linear issue ID
OVD-612

## Summary
Characterize the 1.0 6061 CNC package against all seven named provider envelopes using offline data. One test-only file evaluates 42 provider/material/tolerance combinations and asserts six decision-relevant invariants. This is decision evidence, not provider admission or a provider count.

## Problem
The runbook's nominal package did not have one cross-portfolio characterization. Material spelling and explicit tolerance produce different conservative dispositions that must stay visible.

## Scope
Only `worker/src/adapters/namedPortfolioPackageEligibility.test.ts`. The file states geometry, unit, finish and attestation limitations; it does not enable dispatch or change any provider envelope. The 308-line test is one matrix and its shared input builders, kept together for a standalone reviewable characterization.
