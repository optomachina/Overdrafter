OVD-804. Third of four PRs split from #834 (head 969dc15e): the Jarvis web thread UI and the DEV-only preview route. **Stacked on the gate PR #837** (base `bwilson/ovd-804-gate`), because `react` inside `src/features/jarvis/thread/` needs that allowance.

## What
- `JarvisThread.tsx` (without the 3D viewer): status lanes, skippable decision cards, pause/cancel controls, offline state and retry, result pictures, dimensions, and STEP/GLB download links.
- `ThreadDialog.tsx`: focus-trapped dialog and cancel sheet.
- `thread.css`.
- `preview-source.ts` plus the synthetic `iso.png`, `top.png` and `plate.step` fixtures (and the README). In this PR the preview emits PNG and STEP only; `plate.glb` arrives in the viewer PR.
- `src/pages/JarvisThreadPreview.tsx` and the `/dev/jarvis-thread` route in `App.tsx`, inside an `import.meta.env.DEV` guard so production builds drop it.
- Tests: `JarvisThread.test.tsx` (viewer cases moved to the viewer PR), `ThreadDialog.test.tsx`, `preview-source.test.ts`.

Review fixes from 969dc15e included here:
- Only stage and state changes are announced to screen readers, not the elapsed timer.
- The cancel sheet's first button reads KEEP COOKING.
- Idempotency keys reset after the command lands (applied or rejected).
- Artifact links pass an https/relative/blob allowlist; `javascript:` and `data:` URIs are dropped.
- `randomUUID` fallback for idempotency keys.
- The ●/○ radio glyphs are hidden from screen readers.

**Transport dependency:** this branch also carries the transport commit, cherry-picked from #836 (`client.ts`, `event-source.ts`, `supabase-source.ts`, and their tests), because the thread imports those types. Until #836 lands, this PR's diff includes those files. Once #836 merges they drop out on rebase, since the changes are identical.

**Design:** the `docs/DESIGN.md` 2026-10-15 row from #834 is deliberately left out. #791 adds the approved 2026-10-16 row, and this one conflicted with it. This split makes no design changes; a separate design round follows.
