## Summary
`scripts/jev-client.mjs` sent no Authorization header and relied on the Claude Code proxy to inject the TypeSafe credential, so calls outside the proxy failed with `http_403`.

Now, if `TYPESAFE_API_KEY` is set and non empty, the client sends `Authorization: Bearer <key>`. Otherwise behavior is unchanged. The header comment is updated.

The key is read only to build that one header. Tests turned up one real leak path: `sanitizeToken` kept service supplied strings (model name, network error code) that could echo the key. `sanitizeToken` now returns `redacted` if its input contains the key, and the network reason code goes through it too.
