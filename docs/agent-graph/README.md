# Agent graph spec

`graph.v1.yaml` is the tool-neutral draft definition of how work routes between OverDrafter agents, except reviewer routing. AGENTS.md, CLAUDE.md, Hermes config and Grok Bot skills are adapters: they point to the applicable authoritative sources and must not redefine routing. Draft: runtimes are not wired yet. Bump `version` on any change; a change that loosens a gate needs the root agent's countersign and Blaine's OK.

`node scripts/validate-agent-graph.mjs` fails closed on policy, not only shape. The graph must keep the mandatory routes (sensitive scope goes to Release from triage and to Opus from Jev, QA hands off to the merge gate, and protected merges go to Release) and every mandatory merge gate. The validator currently requires the draft graph's default-path review to span two model families, counting only unconditional reviewer edges; this validates the draft structure, not authoritative reviewer routing. A QA verdict may carry over a rebase only when the recomputed `diff_id` is equal (`rebase_reuse: diff-id-equal`); an equal patch ID is never enough, and a `diff_id` failure rejects reuse (`rebase_reuse_on_error: reject`).

Reviewer routing remains owned by [model-routing.v2.yaml](../../scripts/fixtures/agent-graph/model-routing.v2.yaml) and enforced by [built-by.mjs](../../scripts/agent-graph/built-by.mjs), as documented in [agent-pr-tags.md](../agent-pr-tags.md). Claude builds require fresh-session `claude-opus` review; OpenAI builds route to `claude-sonnet`, with additional reviews where required by risk. OpenAI must not review Claude builds. The draft graph's reviewer section is non-authoritative until it models builder-family routing; its unconditional Sonnet/Codex edges do not override these rules.
