# New Feature Checklist

- [ ] Capture request.
- [ ] Add the idea and evidence link to the Linear portfolio index.
- [ ] Apply the promotion gate in `ROADMAP.md`.
- [ ] If promoted, search for and create/update one bounded Linear issue.
- [ ] Paste template content only for the promoted issue.
- [ ] Scope with `feature-scoper` / `linear-feature-scoper`.
- [ ] Confirm acceptance criteria.
- [ ] Create branch from issue ID.
- [ ] Implement minimal safe change.
- [ ] Run tests.
- [ ] Run QA checklist.
- [ ] Prepare the PR and update the single rolling Linear comment.
- [ ] Follow the `Ready for review` and `Complete` gates in `AGENTS.md`.
