## Export control (OVD-723, PR #677)

Geomiq is a foreign provider (United Kingdom). Sending a controlled file to it
is an export, so the ITAR/EAR upload block (OVD-723, PR #677) applies to Geomiq
in full:

- PR #677 names `geomiq` (with `weerg`) in its explicit foreign provider rule,
  `export_foreign_provider_requires_clean_declaration`. Dispatch is denied
  unless the job has a clean declaration, no pending marking review, and a
  clean scan of record for every file the part sends. Unknown providers are
  also treated as foreign.
- Until #677 and its migration land, the Geomiq dispatch path cannot run at
  all. Eligibility is `unavailable` before any session read, the definition is
  not registered in `worker/src/adapters/index.ts`, and the envelope is not in
  `REVIEWED_PROVIDER_DISPATCH_ENVELOPES`. This PR changes none of that.
- Going live is blocked on #677. Do not register the adapter, set
  `liveAdapter: true`, or record an approved admission revision until the #677
  migration is applied and the OVD-319 certification walk covers Geomiq.
- Controlled or uncertain files are never retried around a block. Nothing here
  rotates IPs, solves a CAPTCHA, or paces requests to look human. There is no
  default daily quote cap; an admin may set one per supplier (OVD-829).
