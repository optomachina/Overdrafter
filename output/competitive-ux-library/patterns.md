## Highest-value OverDrafter concept briefs

### 1. Intake reconciliation strip

After batch upload, show one row per inferred part package: CAD, drawing, supporting files, parse state, pairing confidence, and a one-click “Review pairing.” Never silently merge duplicate or weakly matched filenames.

### 2. Requirement evidence drawer

For each normalized requirement, show source text, page/region, confidence, reviewer, provider-specific interpretation, and intentional deviation history. The normalized value is editable, but source evidence is immutable.

### 3. Quote decision workspace

Keep the existing independent price-versus-working-days scatter and provider-grouped rows. Add a selected-response detail that explains validity, response time, origin evidence, requirement snapshot, exceptions, and whether the result is instant, manually reviewed, or still TBD.

### 4. Revision impact checkpoint

When a new CAD or drawing revision arrives, summarize changed files, stale requirements, affected quote rounds, selected offers, containing assemblies/projects, and open review issues before letting the user adopt it.

### 5. Neutral supplier shortlist

For packages that cannot or should not be auto-quoted, show candidates with role (direct fabricator, network, broker, software storefront), verified capabilities, location/origin evidence, certifications, and official RFQ link. Do not rank a paid partner above a better-fit supplier without labeling the commercial relationship.

## Open research gaps

- Logged-in mobile behavior, keyboard paths, and recovery states for most quoting platforms.
- Detailed public UI evidence for Weerg, Fractory, Quickparts, and Protolabs Network after quote creation.
- Whether provider-network platforms disclose the actual manufacturing facility before order, after order, or never.
- How Paperless Parts and DigiFabster customers configure customer-facing field precedence when PDF notes conflict with structured inputs.
- Accessibility behavior of third-party 3D canvases and markup controls.
